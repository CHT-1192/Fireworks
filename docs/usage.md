# 操作与参数

![界面](preview/ui.png)

| 操作 | 键 / 按钮 |
| --- | --- |
| 暂停 / 继续 | 空格 或「暂停」 |
| 放一发 | R 或「放一发」；**点/触摸画面**则在那个位置炸一发 |
| 收起 / 显示面板 | Esc 或「收起」（收起后左上角留一个「控制台」按钮把面板叫回来；`?ui=0` 是彻底无 UI，连它也不留） |
| 换种子 | 「随机」（数字）；「每日」= 今天这一场（同一天永远是同一个种子） |
| 换开场 | 往种子里敲字母 —— 有一个词能让开场变成参考图风格（见下） |
| 重放 / 存图 | 「重放」/「存图」 |
| 分享 | 「链接」：把这一场的 `seed`（与非默认的场景/预算）拼到当前页面地址上 |
| 全屏 | 「全屏」（Esc 退出；录制中 Esc 优先停录制） |
| 录制 | 「录制」：录成 WebM，再点一次或按 Esc 停止（录满 30 秒自动停） |
| 画面容量 | 「绘制预算」滑块（80~1500，默认 450） |

在种子框里打字时，空格 / R 让位给输入（那是彩蛋的输入）；回车、或点一下画面，
就把键盘还给快捷键，Esc 任何时候都有效。
点击发射走 pointer 事件，所以手机触摸同样可用（canvas 已设 `touch-action: none`）。

## 录制

- **只录画布**：`canvas.captureStream()` 抓的是 canvas 自己画的东西，面板、HUD、
  底部的录制指示条都是浮在上面的 DOM，天然不在画面里；录制期间自动收起面板只是
  让你看着干净，按 Esc 或点指示条上的「停止」结束。
- 编码交给浏览器（VP9 → VP8 兜底），**没有依赖也没有素材**。
- **种子写进元数据**：MediaRecorder 没有写 tag 的接口，所以录制结束时自己往 WebM
  的 EBML 里写一个 `Tags`（`SEED`）—— 详见 `src/ebml.js` 顶部注释（关键是覆盖
  muxer 在头部留下的 Void 填充块，既在前部又零偏移）。用 `ffprobe` 能看到：
  `"tags": { "encoder": "Chrome", "SEED": "7" }`。
- 文件名也带场景与种子，例如 `fireworks_random_seed7_2s.webm`。

URL 参数：`?seed=7`、`?scene=classic|random`、`?frames=90`、`?still=1`、`?ui=0`、`?max=900`、
`?w=924&h=691`

* `frames=N` 先走 N 个固定步再定格（第 1 帧 = `step(0)`）；`still=1` 等价于 `frames=1`
* `ui=0` 隐藏全部 UI；`w`/`h` 钉死逻辑坐标系（构图与窗口大小无关，方便截图与复现）

## 分享与托管

「链接」会把这一场的 `seed`（以及非默认的场景与预算）拼到**当前页面地址**上，
所以托管在子路径下也照样能用。

想在 GitHub Pages 上挂一个链接：`npm run build` 会顺手在 `docs/` 里放一份同样的产物，
于是仓库 Settings → Pages 选 **main 分支 / `/docs` 目录** 就能直接拿到
`https://<用户名>.github.io/<仓库名>/`（那份产物每次构建都重写，不会过期）。
